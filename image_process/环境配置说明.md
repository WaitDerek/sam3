# image_process 环境配置说明
本文档说明 `image_process` 交付代码的运行环境。所有命令默认在仓库根目录进入 `image_process` 后执行：

## Python 环境
```bash
conda create -n sam3 python=3.10 -y
conda activate sam3
```

## 安装依赖

基础依赖记录在 `requirement.txt`：

```bash
pip install -r requirement.txt
```

## 目录约定

交付代码只依赖 `image_process` 内的相对目录：

```text
dataset/    # 本地输入和中间数据，不提交 Git
out/        # 检测、试验和临时点云输出，不提交 Git
changan/    # 已验收交付归档，不提交 Git
configs/    # 可提交的稳定检测参数
```

脚本和配置文件不应写死本机绝对路径。需要访问外部移动盘或临时目录时，通过命令行参数传入路径。

## 快速自检

```bash
python -m py_compile \

  run_material_segmentation.py \
  repair_material_segmentation.py \

python run_material_segmentation.py --help

```

如果需要验证 JSON 配置：

```bash
python - <<'PY'
import json
from pathlib import Path

for path in [
    Path("configs/object_segmentation_params.json"),
    Path("configs/material_detection_registry.json"),
    *Path("configs/materials").glob("**/*.json"),
]:
    json.loads(path.read_text(encoding="utf-8"))

print("json ok")
PY
```
