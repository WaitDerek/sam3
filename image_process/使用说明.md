命令默认在 `sam3` 仓库根目录执行。Linux/WSL 使用 `/` 路径，行尾用 `\` 续行；Windows PowerShell 使用 `\` 路径，行尾用 `` ` `` 续行。

运行报错、目录写错、CUDA 不可用或 GPU 降频等排查见 [问题处理.md](问题处理.md)。

## 3. 推荐流程

```text
extract.py
  -> raw_depth_to_png.py / resize_depth_to_rgb.py（可选）
  -> align_dataset.py
  -> run_material_segmentation.py / detect_material_bgr.py（可选）
  -> repair_material_segmentation.py / clean_container_fps.py（可选历史修复）
  -> labelstudio_json_to_masks.py（可选人工标注）
  -> align_dataset.py
  -> mask_depth_to_pcd.py
  -> visualize_pcd.py
```

交付前检查：

- `bgr/`、`depth/`、`masks/`、`metadata/`、`overlays/`、`pcd/` 是否一一对应。
- `masks/` 是否完整包住目标且未包含料箱格子、泡棉、桌面等背景。
- `overlays/` 是否有明显漏检、误检、粘连未拆分。
- `metadata/` 中标签是否为中文物料名。

### 3.1 分割异常处理和补跑策略

当模型分割出现漏检、误检、边缘不完整、粘连未拆分、料箱或泡棉被误纳入时，优先按“小范围验证 -> 固化参数 -> 批量补跑 -> 重新生成 PCD -> 对齐”的顺序处理，不要一开始全量覆盖。

处理顺序：

```text
1. 先看 overlays，确认问题属于漏检、误检、目标数错误、边缘不完整、空洞或粘连。
2. 用 detect_material_bgr.py 针对单张或少量 stem 试 prompt 和阈值。
3. 单张验证通过后，把 prompt 和阈值写入 configs/materials/<物料名>/<场景>.json。
4. 用 run_material_segmentation.py 按物料或 profile 补跑。
5. 若是历史空结果或固定难例，可用 repair_material_segmentation.py。
6. 更新 masks 后重新执行 mask_depth_to_pcd.py。
7. 最后用 align_dataset.py 以 overlays 或 bgr 为基准对齐。
```

常见问题和处理：

```text
漏检：增加更具体的目标 prompt；降低 --min-score；适当降低 --min-area-frac。
误检：在 prompt 中加入 object only、not crate、not foam、not table；提高 --min-score；加入 --max-area-frac、--max-bbox-fill-frac。
目标数不对：用 --max-instances 控制最大数量；粘连时先试 --split-components，再试 --kmeans-split-instances。
边缘不完整：补充完整外形描述；适当降低 --min-score；使用 --mask-close-kernel 平滑闭合边缘。
中间空洞：业务要求整体 mask 时加 --fill-holes；长方形塑料件可结合 --fill-convex。
白色泡棉误入：prompt 中写 not white foam；必要时加 --exclude-bright-pixels。
料箱格子误入：prompt 中写 black object in bin cell, object only, not blue crate grid。
遮挡过高：prompt 中写 visible complete object only；用较严格的面积和 bbox 阈值，无法判断时输出 0 目标并进入人工复检。
```

```text
1. 新建 Project。
2. Data Import 选择 Local files。
3. 导入 dataset/<物料目录>/bgr 或需要人工复检的图片目录。
4. Labeling Setup 选择 Semantic Segmentation with Polygons。
```

标注规则：

```text
只圈目标本体。
不要圈料箱格子、泡棉、桌面、阴影、反光和红色框。
多个可见目标要分别标注。

中间镂空但业务要求整体 mask 的物料，按整体外轮廓标注，后续转换时生成整体 mask。
```

导出：

```text

```

## 5. 脚本说明

### 5.1 extract.py

功能：从 RealSense `.bag` 中按间隔抽取 `bgr/depth`，也可将多段采集合并为统一目录。

实际使用时需要把 `--bag-dir`、`--output-root`、`--source-root`、`--merge-output` 改成当前电脑上的数据存放和输出位置。一个零件有多个 bag 时，先分别抽取到 `extracted`，再用 `--merge` 合并；`--merge-name` 使用对应零件或物料目录名。

参数：

```text
--bag-dir：输入 .bag 文件目录。
--output-root：抽帧输出根目录。
--save-interval：保存间隔，数值越大抽帧越少。
--merge：启用合并模式。
--source-root：合并模式下的来源根目录。
--merge-output：合并模式下的输出根目录。
--merge-name：合并后的目录名。
--apply：真正执行写入或移动；不加时用于预览。
```

Linux/WSL：

```bash
python image_process/extract.py \
  --bag-dir dataset/raw \
  --output-root dataset/extracted \
  --save-interval 10

python image_process/extract.py \
  --merge \
  --source-root dataset/extracted \
  --merge-output dataset \
  --merge-name merged_ktxfk \
  --apply
```

Windows PowerShell：

```powershell
python image_process\extract.py `
  --bag-dir dataset\raw `
  --output-root dataset\extracted `
  --save-interval 10

python image_process\extract.py `
  --merge `
  --source-root dataset\extracted `
  --merge-output dataset `
  --merge-name merged_ktxfk `
  --apply
```

```text
--stem：指定输出文件名主干。
```

### 5.4 align_dataset.py

功能：以某个目录为基准，删除其他目录中无法一一对应的多余文件。

第一次整理原始数据时通常以 `bgr` 为基准；人工删除过不合格可视化结果后，通常以 `overlays` 为基准同步删除 `bgr/depth/masks/metadata/pcd` 中的同名文件。

参数：

```text
root：数据集目录。
--base：基准目录，常用 overlays 或 bgr。
--targets：需要对齐的目录。
--patterns：文件名匹配规则。
--apply：真正删除；不加时只预览。
```

Linux/WSL：

```bash
python image_process/align_dataset.py \
  dataset/merged_ktxfk \
  --base overlays \
  --targets bgr depth masks metadata pcd \
  --apply
```

### 5.6 detect_material_bgr.py

功能：SAM3 文本 prompt 分割主入口，可处理单张、指定 stem、列表或目录。

输入目录一般改成合并后的 `bgr` 目录，输出目录改成对应物料目录或临时复检目录。批量处理整个目录时删除 `--image-stem`；只复检单张或少量图片时保留 `--image-stem` 或使用 `--image-list`。

参数：

```text
--input-dir：输入 bgr 目录。
--output-dir：输出目录。
--image：单张图片路径。
--image-list：待处理图片列表。
--image-stem：只处理指定文件名主干。
--label：写入 metadata 的中文标签。
--text-prompt：SAM3 文本提示词。
--min-score：最低置信度。
--max-instances：最多保留目标数量。
--fill-holes：填充 mask 内部空洞。
--skip-existing：跳过已有结果。
```

Linux/WSL：

```bash
python image_process/detect_material_bgr.py \
  --input-dir dataset/merged_ktxfk/bgr \
  --output-dir out/merged_ktxfk \
  --label 空调新风口总成 \
  --image-stem 20260527_145449__000248 \
  --text-prompt "black rectangular hollow automotive HVAC fresh air inlet plastic part, object only, not foam or crate" \
  --max-instances 2 \
  --fill-holes
```

Windows PowerShell：
