# image_process 使用说明

命令默认在 `sam3` 仓库根目录执行。Linux/WSL 使用 `/` 路径，行尾用 `\` 续行；Windows PowerShell 使用 `\` 路径，行尾用 `` ` `` 续行。

## 1. 环境配置

CUDA 检查和下载入口：

- 支持 CUDA 的 GPU 列表：<https://developer.nvidia.com/cuda/gpus>
- NVIDIA 显卡驱动下载：<https://www.nvidia.com/Download/index.aspx>
- CUDA Toolkit 下载：<https://developer.nvidia.com/cuda-downloads>
- WSL CUDA 官方说明：<https://docs.nvidia.com/cuda/wsl-user-guide/index.html>

Windows PowerShell 检查：

```powershell
nvidia-smi
Get-CimInstance `
  Win32_VideoController |
  Select-Object `
  Name, DriverVersion
python `
  -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'no cuda')"
```

Linux/WSL 检查：

```bash
nvidia-smi || /usr/lib/wsl/lib/nvidia-smi
python \
  -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'no cuda')"
nvcc --version
```

`nvidia-smi` 能显示显卡和驱动，说明驱动可用；`torch.cuda.is_available()` 为 `True`，说明当前 Python 环境能调用 CUDA；`nvcc --version` 只用于确认 CUDA Toolkit 是否安装。WSL 下优先安装 Windows NVIDIA 驱动，不要在 WSL 内安装 Linux 显卡驱动。

## 2. 数据目录

标准目录：

```text
dataset/<物料目录>/
  bgr/
  depth/
  masks/
  metadata/
  overlays/
  pcd/
```

输出约定：

```text
masks/<stem>_mask.png
metadata/<stem>.json
overlays/<stem>_det.jpg
pcd/<stem>.pcd
```

`sam3.1_multiplex.pt` 放在仓库根目录或 `image_process/` 可访问位置，不提交 Git。

## 3. 推荐流程

```text
extract.py
  -> raw_depth_to_png.py / resize_depth_to_rgb.py（可选）
  -> align_dataset.py
  -> run_material_segmentation.py / detect_material_bgr.py
  -> repair_material_segmentation.py / clean_container_fps.py（可选历史修复）
  -> labelstudio_json_to_masks.py（可选人工标注）
  -> align_dataset.py
  -> mask_depth_to_pcd.py
  -> visualize_pcd.py
```

交付前检查：

- `bgr/`、`depth/`、`masks/`、`metadata/`、`overlays/`、`pcd/` 是否一一对应。
- `masks/` 是否完整包住目标且未包含料箱格子、泡棉、桌面等背景。
- `overlays/` 是否有明显漏检、误检、粘连未拆分。
- `metadata/` 中标签是否为中文物料名。

## 4. 脚本说明

### 4.1 extract.py

功能：从 RealSense `.bag` 中按间隔抽取 `bgr/depth`，也可将多段采集合并为统一目录。

参数：

```text
--bag-dir：输入 .bag 文件目录。
--output-root：抽帧输出根目录。
--save-interval：保存间隔，数值越大抽帧越少。
--merge：启用合并模式。
--source-root：合并模式下的来源根目录。
--merge-output：合并模式下的输出根目录。
--merge-name：合并后的目录名。
--apply：真正执行写入或移动；不加时用于预览。
```

Linux/WSL：

```bash
python image_process/extract.py \
  --bag-dir dataset/raw \
  --output-root dataset/extracted \
  --save-interval 10

python image_process/extract.py \
  --merge \
  --source-root dataset/extracted \
  --merge-output dataset \
  --merge-name merged_ktxfk \
  --apply
```

Windows PowerShell：

```powershell
python image_process\extract.py `
  --bag-dir dataset\raw `
  --output-root dataset\extracted `
  --save-interval 10

python image_process\extract.py `
  --merge `
  --source-root dataset\extracted `
  --merge-output dataset `
  --merge-name merged_ktxfk `
  --apply
```

### 4.2 raw_depth_to_png.py

功能：将厂商 `Depth16.raw` 转为 16-bit depth PNG，并可从 `.mfa` 写出相机内参。

参数：

```text
raw：输入 raw 深度文件。
--output-dir：输出目录。
--output：指定输出 PNG 文件。
--stem：指定输出文件名主干。
--endian：raw 字节序。
--mfa：相机 .mfa 文件。
--write-intrinsics：输出内参 JSON。
```

Linux/WSL：

```bash
python image_process/raw_depth_to_png.py \
  dataset/demo/20260604095608625_W1920_H1456_Depth16.raw \
  --output-dir dataset/demo_prepared/depth \
  --mfa dataset/demo/Sensor_00DA2021501.mfa \
  --write-intrinsics dataset/demo_prepared/intrinsic.json
```

Windows PowerShell：

```powershell
python image_process\raw_depth_to_png.py `
  dataset\demo\20260604095608625_W1920_H1456_Depth16.raw `
  --output-dir dataset\demo_prepared\depth `
  --mfa dataset\demo\Sensor_00DA2021501.mfa `
  --write-intrinsics dataset\demo_prepared\intrinsic.json
```

### 4.3 resize_depth_to_rgb.py

功能：将 depth resize 到 RGB 分辨率，并生成标准 `bgr/depth/intrinsic.json` 目录。

参数：

```text
--color：RGB 或 BGR 图片。
--depth：深度图。
--output-dir：输出目录。
--stem：输出文件名主干。
--mfa：相机 .mfa 文件。
--depth-scale：深度缩放比例。
--interpolation：resize 插值方式。
--no-overwrite：不覆盖已有文件。
```

Linux/WSL：

```bash
python image_process/resize_depth_to_rgb.py \
  --color dataset/demo/20260604095608625_W4000_H3000.jpg \
  --depth dataset/demo_prepared/depth/20260604095608625.png \
  --output-dir dataset/demo_rgb_resized_depth
```

Windows PowerShell：

```powershell
python image_process\resize_depth_to_rgb.py `
  --color dataset\demo\20260604095608625_W4000_H3000.jpg `
  --depth dataset\demo_prepared\depth\20260604095608625.png `
  --output-dir dataset\demo_rgb_resized_depth
```

### 4.4 align_dataset.py

功能：以某个目录为基准，删除其他目录中无法一一对应的多余文件。

参数：

```text
root：数据集目录。
--base：基准目录，常用 overlays 或 bgr。
--targets：需要对齐的目录。
--patterns：文件名匹配规则。
--apply：真正删除；不加时只预览。
```

Linux/WSL：

```bash
python image_process/align_dataset.py \
  dataset/merged_ktxfk \
  --base overlays \
  --targets bgr depth masks metadata pcd \
  --apply
```

Windows PowerShell：

```powershell
python image_process\align_dataset.py `
  dataset\merged_ktxfk `
  --base overlays `
  --targets bgr depth masks metadata pcd `
  --apply
```


### 4.6 detect_material_bgr.py

功能：SAM3 文本 prompt 分割主入口，可处理单张、指定 stem、列表或目录。

参数：

```text
--input-dir：输入 bgr 目录。
--output-dir：输出目录。
--image：单张图片路径。
--image-list：待处理图片列表。
--image-stem：只处理指定文件名主干。
--label：写入 metadata 的中文标签。
--text-prompt：SAM3 文本提示词。
--min-score：最低置信度。
--max-instances：最多保留目标数量。
--fill-holes：填充 mask 内部空洞。
--skip-existing：跳过已有结果。
```

Linux/WSL：

```bash
python image_process/detect_material_bgr.py \
  --input-dir dataset/merged_ktxfk/bgr \
  --output-dir out/merged_ktxfk \
  --label 空调新风口总成 \
  --image-stem 20260527_145449__000248 \
  --text-prompt "black rectangular hollow automotive HVAC fresh air inlet plastic part, object only, not foam or crate" \
  --max-instances 2 \
  --fill-holes
```

Windows PowerShell：

```powershell
python image_process\detect_material_bgr.py `
  --input-dir dataset\merged_ktxfk\bgr `
  --output-dir out\merged_ktxfk `
  --label 空调新风口总成 `
  --image-stem 20260527_145449__000248 `
  --text-prompt "black rectangular hollow automotive HVAC fresh air inlet plastic part, object only, not foam or crate" `
  --max-instances 2 `
  --fill-holes
```

### 4.9 labelstudio_json_to_masks.py

功能：将 Label Studio 或 COCO JSON 标注转换为项目标准的 `masks/metadata/overlays`。


### 4.10 mask_depth_to_pcd.py

功能：根据 `bgr + depth + masks` 生成目标级点云，只保留 mask 内的目标点。

参数：

```text

--depth-dir：深度图目录。
--mask-dir：mask 目录。
--output-dir：PCD 输出目录。
--mask-suffix：mask 文件后缀。
--frame：只处理指定文件名主干。
--depth-scale：深度缩放比例。
--overwrite：覆盖已有 PCD。
```

Linux/WSL：

```bash
python image_process/mask_depth_to_pcd.py \
  --dataset-dir dataset/merged_ktxfk \
  --mask-dir dataset/merged_ktxfk/masks \
  --output-dir dataset/merged_ktxfk/pcd \
  --overwrite
```

```powershell
python image_process\mask_depth_to_pcd.py `
```

### 4.12 pixel_to_xyz.py

功能：查询单个像素在深度图中的三维坐标，可用于检查深度、内参和 mask 对齐。

参数：

```text
--dataset-dir：数据集目录。
--depth-dir：深度图目录。
--mask-dir：mask 目录。
--frame：文件名主干。
--pixel：像素坐标，格式如 640,360。
--search-radius：无有效深度时的邻域搜索半径。
--check-mask：同时检查该像素是否在 mask 内。
--json：以 JSON 格式输出。
```

Linux/WSL：

```bash
python image_process/pixel_to_xyz.py \
  --dataset-dir dataset/merged_ktxfk \
  --frame 20260527_145449__000248 \
  --pixel 640,360 \
  --check-mask
```

Windows PowerShell：

```powershell
python image_process\pixel_to_xyz.py `
  --dataset-dir dataset\merged_ktxfk `
  --frame 20260527_145449__000248 `
  --pixel 640,360 `
  --check-mask
```
